# Lumina Studio — Fine Art & Editorial Photography Gallery

An award-winning editorial photography gallery and darkroom archive built from scratch with pure semantic HTML5 and modern CSS3.

## Live Demo
- **Live Site:** `https://deeppurohit7.github.io/photography-gallery/`
- **Source Code:** `https://github.com/deeppurohit7/photography-gallery`

## Core Interactive Features
- **DSLR Viewfinder HUD Hero:** Camera optical heads-up display with live sensor pulse, rule-of-thirds grid, autofocus brackets, and exposure telemetry.
- **Interactive RAW vs. Color-Graded Slider:** 60fps comparison slider utilizing native CSS custom properties and `clip-path` polygon masking.
- **Asymmetric Editorial Masonry:** Magazine-style layout spanning wide and tall dimensions with camera optic tags.
- **Print Studio Configurator:** Interactive sizing and museum-grade framing options with live visual state toggling.
- **Darkroom Lightbox Modals:** Full-screen inspection modal with full EXIF technical data powered by the CSS `:target` pseudo-class.
